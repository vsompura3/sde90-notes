# SDE Plan: 100 study days + 40-day flagship project

- tracker.html: interactive tracker (double-click to open; progress saved in your browser). Tabs: Plan, Projects, Flagship, Machine coding, Concepts, Resources, Stats, Start here.
- STUDY_PLAN.md: the full written plan (generated)
- plan-data.js: study plan source of truth. Edit tasks here, then run `node build.js`
- flagship-data.js: the Beacon flagship project (15 parts, day plan, resume bullets)
- flagship-detail.js: day-by-day detail for the 40 flagship days (key ideas, try-it, numbered steps)
- study-detail.js: day-by-day detail for study days 1-100 (key ideas, try-it, steps, done-when)
- concepts-data.js: 118 plain-language explanations shown in the Concepts tab
- build.js: regenerates STUDY_PLAN.md

Keep all .js files next to tracker.html. Read the "Start here" tab before Day 1.
